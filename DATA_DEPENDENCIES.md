# R data dependency audit

This file records which data are retained in Git and which files are regenerated by the workflow. It is based on a static audit of all `.R` scripts in this repository.

## Retained model inputs

- `Input data/`: country and food domains, Food Balance Sheets, nutrient coefficients, food mappings, loss/waste parameters, and processed-food shares.
- `food_proxy_code_data_reps/input_reps_full/`: model-ready food-proxy inputs, except `GDD_data_2020.gdx`, which exceeds GitHub's per-file size limit and must be obtained from the companion data archive.
- `output data/Price_FAO_fake.xlsx`: synthetic price template for functional testing only. Copy it locally to `output data/Price_FAO.xlsx` before a test run. Authorized ICP prices must never be committed.
- `output data/intensity data.xlsx`: environmental-intensity input used by Step 07.
- `Health model/Death rate.xlsx`, `food factor.xlsx`, `risk factor.xlsx`, `population.xlsx`, and `income group.xlsx`: model-ready health and grouping inputs.
- Figure directories retain R scripts plus non-generated source inputs such as geographic boundaries, RDA tables, income-group tables, population tables, and sensitivity-analysis input workbooks.

## Regenerated intermediates and outputs

- Step 03: `food_proxy_code_data_reps/output_reps_full/`.
- Steps 04-07: age-specific intake workbooks, bounds, population, waste factors, and `all_raw_data_newIntensity.gdx` under `output data/`.
- Step 08: `output data/optimized model output/`.
- Step 09: the `00fig*.xlsx`, price, environmental, nutrient, and demographic figure-ready tables listed in `.gitignore`.
- Steps 10-13: reconstructed intake workbooks, processed-food workbooks, merged health-model inputs, validation CSV files, and health-effect output workbooks under `Health model/`.
- Figure scripts: rendered PNG, SVG, PDF, TIFF, AI, QA, and source-data output bundles.

These files remain on the local computer but are excluded from Git.

## Required files not distributed through GitHub

- `food_proxy_code_data_reps/input_reps_full/GDD_data_2020.gdx`: required by the food-proxy workflow but too large for ordinary GitHub storage.
- `food_proxy_code_data_reps/output_reps_full/FBS_proxy_2020.gdx`: generated by Step 03 and required by Steps 04 and 11.
- Authorized country- and food-specific ICP prices: required for scientific reproduction but restricted from redistribution.
- `carbon_analysis_dzc.R` is a separate FABIO analysis and expects `Z_mass.rds`, `Y.rds`, `X.rds`, `E.rds`, and `items.csv` in an external FABIO directory. These data are not part of the national age-specific diet workflow.
